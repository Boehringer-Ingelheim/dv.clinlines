# Set default values for `drug_admin`

Set default values for `drug_admin`

## Usage

``` r
default_drug_admin()
```

## Value

A list that points to an ex domain dataset and assigns the following
elements:

- `EXSTDTC` as start variable

- `EXENDTC` as end variable

- `EXTRT` as detail variable

- `Drug Administration` as label

- `EXDOSE` as exposure dosage

- `EXDOSU` as dose unit
