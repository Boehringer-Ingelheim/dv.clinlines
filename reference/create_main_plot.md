# Create plot for main view of the dv.clinlines module

`create_main_plot` returns a ggplot object in consideration of chosen
x-axis scale, y-axis sorting type, and time range.

## Usage

``` r
create_main_plot(work_data, y_sort, time_range, colors, height, subjid_var)
```

## Arguments

- work_data:

  Data frame returned by [`create_plot_data()`](create_plot_data.md)

- y_sort:

  Character name of selected y-axis sorting type of the main plot. Can
  be either "alphanum" or "earliest".

- time_range:

  Datetime or numeric vector, length 2. Indicates limits of x-axis in
  main and detail plots.

- colors:

  Named character vector of color hex codes. Must be named after event
  types. Must be of the same length as there are distinct event types to
  plot. Can be generated by a call to
  [`color_lookup()`](color_lookup.md).

- height:

  Box/row height for each subject. Numeric. Must be a single value.

- subjid_var:

  `[character(1)]`

  Character name of the unique subject identifier column in all datasets
  (default is USUBJID). Must be a single value.

## Value

A ggplot object - the main plot of dv.clinlines.
