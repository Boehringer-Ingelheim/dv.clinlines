# Produce a warning for non-available receiver names

Produce a warning for non-available receiver names

## Usage

``` r
check_receiver(receiver_id, module_ids)
```

## Arguments

- receiver_id:

  Character string defining the module that should receive a subject
  identifier from clinlines.

- module_ids:

  Vector of characters defining all available module IDs.

## Value

Logical outcome of the test invisible.
