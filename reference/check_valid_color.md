# Check if colors are valid

Executes an error action in case of wrong color definitions.

## Usage

``` r
check_valid_color(color_palette)
```

## Arguments

- color_palette:

  Vector containing strings that are meant to specify a color, either as
  6-digit hex color starting with the \# symbol, or as R color string
  like received when executing
  [`colors()`](https://rdrr.io/r/grDevices/colors.html).
