# Collapse timepoint and interval columns of hover info table and remove empty rows

Collapse timepoint and interval columns of hover info table and remove
empty rows

## Usage

``` r
collapse_cols(col1, col2, col3, col4)
```

## Arguments

- col1:

  Column holding start dates/days from interval events.

- col2:

  Column holding end dates/days from interval events.

- col3:

  Column holding start dates/days from exp interval events.

- col4:

  Column holding end dates/days from exp interval events.

## Value

Character vector of collapsed dates/days.
